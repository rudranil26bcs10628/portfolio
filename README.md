# Rudranil Ghosh — Simple Portfolio

A beginner-friendly HTML/CSS portfolio following the Builders Day requirements.

## Included
- Responsive navigation
- Hero, About, Skills, Projects, Education and Contact sections
- Flexbox
- CSS Grid
- Hover transitions
- CSS animation
- Mobile/tablet/desktop responsiveness
- No JavaScript or framework

## Before publishing
Replace the example project descriptions, email, GitHub, LinkedIn and education details with your real information.

## Run
Open `index.html` in a browser.
